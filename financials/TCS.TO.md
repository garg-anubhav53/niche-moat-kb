## Business Description

Tecsys Inc. provides supply chain management software (WMS/ERP/SaaS) specializing in:
- Healthcare systems: hospital distribution, IDN (Integrated Delivery Network) supply chains, pharmacy automation
- Complex distribution: pharmaceutical distributors, retail/wholesale complex distribution

**Moat thesis (§3.5 level — unverified §4):**
1. WMS implementation for hospital supply chains = 12–24-month migration cost (retraining clinical/warehouse staff, reintegrating with ERP/EHR systems, re-validating FDA/Health Canada compliance)
2. DSCSA serialization track-and-trace compliance embedded in platform = regulatory dependency for pharmaceutical distributors (DSCSA enforcement Oct 2024 = fresh compliance cycle)
3. 40+ years healthcare distribution domain expertise = proprietary clinical workflow knowledge vs generic WMS competitors
4. AWS marketplace deployment + cloud-native migration path
